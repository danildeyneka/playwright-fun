# auto-hh
## Автоматизированные отклики на все вакансии по вашему фильтру, со сбором вакансий-опросников
#### Обходит фильтр "не смотрел вакансию", открывая и проводя время на каждой из вакансий
#### Среднее время откликов на 200 вакансий ~ 30 мин

### 0. Установите node v20+ LTS (https://nodejs.org/en/download)

### 1. Установите зависимости: (npm / yarn)

```bash
npm install
```

### 2. Настройте params.ts

**VACANCIES_LIST** - ссылка на вашу персонализированную подборку вакансий
**COVER_LETTER** - универсальное сопроводительное письмо
**AUTO_HIDE_SUCCESSFUL_VACANCY** - флаг скрывания вакансии после успешного отклика (чтобы не дублировались в поиске), **true(вкл по умолчанию) / false**
**VACANCY_TITLE_FILTER** - точный фильтр по наименованию искомой специальности в вакансии

### 3. Инициализируйте проект следуя инструкциям в консоли (автоотклики запустятся автоматически)

```bash
npm run init
```

### 4. Для повторных запусков автооткликов после инициализации используйте команду

```bash
npm run start
```

### 5. Если протухнет сессия hh (выйдет уведомление), запустите следующую команду 


```bash
npm run renew-cookie
```

### NOTE: после первоначальной настройки можете запускать скрипт из директории bat/start.bat (win)
### NOTE: также добавлен zarplata.ru (входящий в hh-group), алгоритм действий аналогичный (с 'zp' в скриптах)
